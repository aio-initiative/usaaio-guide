## Overview

Three things you already use turn out to be one thing:

* Decision trees split on the feature with the highest **information gain**.
* Classifiers are trained by minimizing **cross-entropy**.
* VAEs regularize with a **KL divergence** against the prior.

All three are the same framework, and this module is the framework. Getting it once means those three stop being separate formulas to memorize.

## Surprise and entropy

Start with a single event of probability $p$. How *surprising* is it? Whatever "surprise" means, it should satisfy two requirements: a certain event ($p=1$) carries zero surprise, and the surprise of two **independent** events should **add**.

Additivity is the binding constraint. Independent probabilities multiply, and the only continuous functions turning multiplication into addition are constant multiples of the logarithm, with the base picking the constant. So

$$
\text{surprise}(p) = -\log p
$$

with the minus sign because $\log p \le 0$ for a probability. Base 2 gives **bits**. The natural log gives **nats**, which is what deep-learning code uses. $1$ nat $= 1/\ln2 = 1.4427$ bits.

**Entropy** is the average surprise of a distribution:

$$
H(p) = -\sum_x p(x) \log p(x)
$$

It measures how uncertain the distribution is, equivalently, the average number of bits needed to encode a sample from it under an optimal code. A fair coin has $H = 1$ bit. A coin that always lands heads has $H = 0$: nothing is learned from observing it. A uniform distribution over 8 outcomes has $H = 3$ bits, since $2^3 = 8$. For probabilities $(1/2,1/4,1/4)$, entropy in bits is $-(1/2)(-1)-(1/4)(-2)-(1/4)(-2)=1.5$. A code with lengths one, two, and two bits has the same average. Frequent outcomes receive shorter descriptions. Entropy is **maximized by the uniform distribution** and **zero for a deterministic one**. **Shannon's source-coding theorem.** For a source with entropy $H(p)$, the expected length $L$ of an optimal binary code satisfies $H(p) \le L < H(p) + 1$ bits per symbol. Entropy is the hard floor on lossless compression.

By convention $0 \log 0 = 0$, justified by $\lim_{p \to 0} p \log p = 0$: impossible outcomes contribute nothing.

## Cross-entropy and KL divergence

Now two distributions. Suppose the truth is $p$ but you build your code assuming $q$, giving each outcome $x$ a codeword of length $-\log q(x)$. The average cost is the **cross-entropy**:

$$
H(p, q) = -\sum_x p(x) \log q(x)
$$

Outcomes still occur with probabilities $p(x)$, which is why $p$ does the weighting, but each one costs $-\log q(x)$, the length your model's code gives it. The **excess** cost from being wrong is the **Kullback-Leibler divergence**:

$$
D_{\mathrm{KL}}(p \Vert q) = \sum_x p(x) \log \frac{p(x)}{q(x)}
$$

and by construction these compose exactly:

$$
\boxed{H(p, q) = H(p) + D_{\mathrm{KL}}(p \Vert q)}
$$

Cross-entropy is the *unavoidable* cost $H(p)$ plus the *avoidable* penalty $D_{\mathrm{KL}}$.

This identity is why training works the way it does. When you minimize cross-entropy over model parameters, $p$ is the fixed data distribution, so $H(p)$ is a **constant** you cannot change. Minimizing $H(p,q)$ is therefore *exactly* minimizing $D_{\mathrm{KL}}(p \Vert q)$, pulling the model toward the data distribution. Cross-entropy loss and maximum likelihood and KL minimization are three names for one procedure.

### KL is non-negative

$D_{\mathrm{KL}} \ge 0$, with equality only when $p = q$. This is **Gibbs' inequality**. The proof uses Jensen's inequality from [Convex Optimization](2.5-DL5-advanced-optimization.md#convex-functions): for a convex function $f$, the average of $f$ is at least $f$ of the average. Apply it once to the convex function $-\log$. The sums run over the outcomes with $p(x) > 0$, since the others add nothing to the KL:

$$
D_{\mathrm{KL}}(p \Vert q) = -\sum_{p(x)>0} p(x) \log \frac{q(x)}{p(x)}
\;\ge\; -\log \sum_{p(x)>0} p(x) \frac{q(x)}{p(x)}
= -\log \sum_{p(x)>0} q(x) \;\ge\; -\log 1 = 0
$$

The last sum is 1, or less than 1 if $q$ puts probability on outcomes where $p(x) = 0$. Either way, $-\log$ of it is at least 0. Equality needs both steps to be equalities: $q(x)/p(x)$ constant wherever $p(x) > 0$, and no probability of $q$ anywhere else. With both summing to 1, that forces $p = q$. This is the theorem behind the VAE's **evidence lower bound** (ELBO). It is a lower bound because the term dropped to get it is a KL, and a KL cannot be negative.

### KL is not a distance

$D_{\mathrm{KL}}(p \Vert q) \ne D_{\mathrm{KL}}(q \Vert p)$ in general. It is not symmetric and fails the triangle inequality, so it is called a **divergence** rather than a distance. The order of the arguments changes how a fitted model behaves:

* **Forward KL**, $D_{\mathrm{KL}}(p \Vert q)$, is **mass-covering**. Wherever $p$ has mass and $q$ has none, $\log(p/q) \to \infty$, so $q$ is forced to cover every outcome $p$ can produce, and will smear across the gaps between $p$'s peaks (its **modes**).
* **Reverse KL**, $D_{\mathrm{KL}}(q \Vert p)$, is **mode-seeking**. Regions where $q$ is near zero contribute nothing regardless of $p$, so $q$ can safely ignore most of $p$ and concentrate on one mode.

A VAE meets the reverse form through its training objective. The log-likelihood exceeds the ELBO by exactly $D_{\mathrm{KL}}(q_\phi(z\mid x) \Vert p(z\mid x))$, so maximizing the ELBO pulls the approximation $q_\phi$ toward the true posterior in the mode-seeking direction. As a result, a VAE's approximate posterior tends to be too narrow. Posterior collapse is a different failure, driven by the other KL in the [VAE loss](2.13-RP1-representation-learning-autoencoders-vaes-latent-spaces.md#lesson-vae), $D_{\mathrm{KL}}(q_\phi(z\mid x) \Vert p(z))$ against the prior. When the decoder can model $x$ without $z$, that term is cheapest at zero: every $q_\phi(z\mid x)$ becomes the prior itself, as broad as the prior and carrying no information about $x$.

### Continuous distributions, and two Gaussians

For densities the sums become integrals: $D_{\mathrm{KL}}(p \Vert q) = \int p(x)\log\frac{p(x)}{q(x)}\,dx$, and the same Jensen argument keeps it non-negative, zero only when $p = q$. Entropy does not carry over as cleanly. $-\int p \log p$, the **differential entropy**, can be negative and changes when you rescale $x$, so it is not a count of bits. KL compares two densities through their ratio, so a rescaling cancels out and KL keeps its meaning.

The case that keeps appearing is two one-dimensional Gaussians, $p = \mathcal{N}(\mu_1, \sigma_1^2)$ and $q = \mathcal{N}(\mu_2, \sigma_2^2)$. The log-ratio is

$$
\log\frac{p(x)}{q(x)} = \log\frac{\sigma_2}{\sigma_1}
- \frac{(x - \mu_1)^2}{2\sigma_1^2} + \frac{(x - \mu_2)^2}{2\sigma_2^2},
$$

and only two expectations under $p$ are needed. $\mathbb{E}_p[(x-\mu_1)^2] = \sigma_1^2$ by definition, and $\mathbb{E}_p[(x-\mu_2)^2] = \sigma_1^2 + (\mu_1 - \mu_2)^2$, the variance plus the squared offset of the center. So

$$
\boxed{\;D_{\mathrm{KL}}\big(\mathcal{N}(\mu_1,\sigma_1^2)\,\Vert\,\mathcal{N}(\mu_2,\sigma_2^2)\big)
= \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{1}{2}\;}
$$

For independent coordinates, as with a diagonal covariance, the KLs of the coordinates add. Two special cases do most of the work in practice:

* **Equal variances**, $\sigma_1 = \sigma_2 = \sigma$: the log term is zero, and $\sigma_1^2 / (2\sigma_2^2) = \tfrac12$ cancels the $-\tfrac12$, leaving $(\mu_1 - \mu_2)^2 / 2\sigma^2$. A KL between Gaussians of fixed shared variance is a scaled squared error between their means, which is why [diffusion models](3.16-GM4-generative-adding-noise.md#lesson-removing-noise) train on a squared error.
* **Against the standard normal**, $\mu_2 = 0$ and $\sigma_2 = 1$: the result is $\tfrac12(\mu_1^2 + \sigma_1^2 - 1 - \log\sigma_1^2)$, the regularizer in every [VAE](2.13-RP1-representation-learning-autoencoders-vaes-latent-spaces.md#lesson-vae), summed over latent dimensions.

<ProblemCard id="it-one-bell-for-two-bumps" />

The formula can be checked against a direct Monte Carlo average of the log-ratio, and it shows the asymmetry in numbers:

```python
import numpy as np

def kl_gauss(m1, s1, m2, s2):
    """KL( N(m1, s1^2) || N(m2, s2^2) ), in nats."""
    return np.log(s2 / s1) + (s1**2 + (m1 - m2) ** 2) / (2 * s2**2) - 0.5

rng = np.random.default_rng(0)
x = rng.normal(1.0, 2.0, size=2_000_000)                  # draws from p = N(1, 2^2)
log_p = -0.5 * np.log(2 * np.pi * 4.0) - (x - 1.0) ** 2 / 8.0
log_q = -0.5 * np.log(2 * np.pi) - x**2 / 2.0             # q = N(0, 1)

print(f"KL(N(1, 4) || N(0, 1)), closed form : {kl_gauss(1, 2, 0, 1):.4f}")
print(f"                        Monte Carlo : {np.mean(log_p - log_q):.4f}")
print(f"KL(N(0, 1) || N(1, 4)), closed form : {kl_gauss(0, 1, 1, 2):.4f}")
print(f"equal variances, means 3 apart, sd 2: {kl_gauss(3, 2, 0, 2):.4f} = 3^2 / (2 * 2^2)")
```

```output
KL(N(1, 4) || N(0, 1)), closed form : 1.3069
                        Monte Carlo : 1.3081
KL(N(0, 1) || N(1, 4)), closed form : 0.4431
equal variances, means 3 apart, sd 2: 1.1250 = 3^2 / (2 * 2^2)
```

Here $\mathcal{N}(1, 4)$ means variance 4. The wide $p$ measured against the narrow $q$ costs almost three times as much as the reverse, the mass-covering penalty from the list above: $p$ puts mass in the tails where the standard normal has almost none.

## Mutual information

How much does learning $Y$ tell you about $X$? Compare the uncertainty in $X$ before and after. $H(X \mid Y)$ is the average uncertainty left in $X$ once $Y$ is known: $H(X \mid Y) = -\sum_{x,y} p(x,y)\log p(x \mid y)$.

$$
I(X; Y) = H(X) - H(X \mid Y)
$$

Equivalently, and more revealingly, it is the KL divergence between the joint distribution and what the joint *would* be if the variables were independent:

$$
I(X; Y) = D_{\mathrm{KL}}\big(p(x,y) \,\Vert\, p(x)p(y)\big)
$$

Independence means exactly $p(x,y) = p(x)p(y)$, so mutual information measures how far from independent the pair is. It is symmetric and non-negative, the latter following immediately from Gibbs.

**Decision trees are mutual-information maximizers.** The information gain of a split is

$$
\text{IG} = H(\text{labels}) - H(\text{labels} \mid \text{feature})
$$

which is $I(\text{labels}; \text{feature})$ verbatim when the impurity is entropy. The linked decision-tree lesson works its example with Gini impurity, which runs the same search but is not itself mutual information, and notes the two measures almost always rank splits alike. Choosing the split with highest information gain is choosing the feature most statistically dependent on the label. The estimate is biased upward when the variables are nearly independent, so a small positive information gain on a handful of examples can be pure chance. The last code block of the From scratch section below confirms the two formulas agree numerically. **Post-processing cannot create information.** If $X\to Y\to Z$ is a Markov chain (so $Z$ depends on $X$ only through $Y$), then $I(X;Z)\le I(X;Y)$. Every layer of a network can only lose information about the input, never gain it. A representation $z = f(x)$ satisfies $I(z;y)\le I(x;y)$: the features can never be more informative about the label than the raw input was. This sounds like it makes representation learning pointless, and the resolution is important: the goal is not to *preserve* information but to make it **accessible**. The raw pixels contain everything, but not in a form a linear classifier can use. A good representation discards nuisance information and reorganizes what remains so a simple model can exploit it.

### The information bottleneck

Find $Z$ that is maximally informative about $Y$ while maximally compressive of $X$:

$$\min_{p(z\mid x)}\ I(X;Z) - \beta\,I(Z;Y).$$

$\beta$ trades compression against prediction. At $\beta\to0$ the optimum is a constant $Z$, where $I(X;Z) = I(Z;Y) = 0$, and at $\beta\to\infty$ it is $Z = X$, where $I(X;Z) = H(X)$ and $I(Z;Y) = I(X;Y)$.

The **variational information bottleneck** is the practical descendant: a [$\beta$-VAE](2.13-RP1-representation-learning-autoencoders-vaes-latent-spaces.md#lesson-vae) with a supervised term.

## From scratch

All three functions are one line each, and the identities are worth checking rather than trusting.

```python
import numpy as np

def entropy(p):
    p = np.asarray(p, dtype=float)
    nz = p > 0                                     # 0 log 0 = 0 by convention
    return -np.sum(p[nz] * np.log2(p[nz])) + 0.0   # + 0.0 turns -0.0 into 0.0

def cross_entropy(p, q):
    p, q = np.asarray(p, float), np.asarray(q, float)
    nz = p > 0
    return -np.sum(p[nz] * np.log2(q[nz]))

def kl(p, q):
    p, q = np.asarray(p, float), np.asarray(q, float)
    nz = p > 0
    return np.sum(p[nz] * np.log2(p[nz] / q[nz]))

for name, p in [("fair coin      ", [0.5, 0.5]),
                ("biased 0.9/0.1 ", [0.9, 0.1]),
                ("certain        ", [1.0, 0.0]),
                ("uniform over 8 ", [1/8] * 8)]:
    print(f"  {name} H = {entropy(p):.4f}")

p = np.array([0.5, 0.25, 0.15, 0.10])
q = np.array([0.25, 0.25, 0.25, 0.25])
print(f"\nH(p)      = {entropy(p):.6f}")
print(f"H(p,q)    = {cross_entropy(p, q):.6f}")
print(f"KL(p||q)  = {kl(p, q):.6f}")
print(f"H(p) + KL = {entropy(p) + kl(p, q):.6f}")
```

```output
  fair coin       H = 1.0000
  biased 0.9/0.1  H = 0.4690
  certain         H = 0.0000
  uniform over 8  H = 3.0000

H(p)      = 1.742738
H(p,q)    = 2.000000
KL(p||q)  = 0.257262
H(p) + KL = 2.000000
```

The decomposition is exact. Note $H(p,q) = 2.000000$ against a uniform $q$ over four outcomes, unsurprising, since coding with a uniform model costs $\log_2 4 = 2$ bits per symbol no matter what the data is.

Gibbs' inequality and the asymmetry are equally checkable:

```python
rng = np.random.default_rng(0)
worst = np.inf
for _ in range(100_000):
    a, b = rng.random(5), rng.random(5)
    a, b = a / a.sum(), b / b.sum()
    worst = min(worst, kl(a, b))
print(f"minimum KL over 100,000 random pairs: {worst:.6f}")
print(f"KL(p||p) = {kl(p, p):.2e}")
print(f"KL(p||q) = {kl(p, q):.6f}")
print(f"KL(q||p) = {kl(q, p):.6f}")
```

```output
minimum KL over 100,000 random pairs: 0.000405
KL(p||p) = 0.00e+00
KL(p||q) = 0.257262
KL(q||p) = 0.264723
```

A hundred thousand random pairs and not one negative value, consistent with Gibbs, which of course *proves* it in a way sampling cannot. Swapping the arguments changes the answer, so KL is not a distance.

Finally, that information gain and mutual information are the same quantity:

```python
# 14 examples, a binary feature, a binary label.
#   feature=0 -> [4 yes, 1 no],  feature=1 -> [3 yes, 6 no]
groups = {0: np.array([4, 1]), 1: np.array([3, 6])}
total = sum(g.sum() for g in groups.values())
parent = sum(groups.values()) / total

H_parent = entropy(parent)
H_children = sum((g.sum() / total) * entropy(g / g.sum()) for g in groups.values())
print(f"information gain     = {H_parent - H_children:.6f}")

joint = np.stack([groups[0], groups[1]]).astype(float) / total   # [feature, label]
px = joint.sum(axis=1, keepdims=True)
py = joint.sum(axis=0, keepdims=True)
print(f"KL(joint || product) = {kl(joint.ravel(), (px * py).ravel()):.6f}")
```

```output
information gain     = 0.151836
KL(joint || product) = 0.151836
```

Identical. The entropy-difference definition used by [decision trees](1.29-ML10-decision-trees-knn.md) and the divergence-from-independence definition are the same number, reached from opposite directions.
