## Overview

A **loss function** turns how wrong a prediction is into one number for training to minimize. The choice decides what the model recovers, the mean or the median or a probability, and how hard the model is pushed when it is wrong. Almost every standard loss comes from one recipe, **maximum likelihood**: assume a shape for the noise, and choose the predictions that make the observed data most probable. The recipe says when each loss applies.

Round 1 asks which loss goes with which problem, why a classifier trains on cross-entropy and not squared error, and what RMSE, MAE and $R^2$ measure when a regressor is scored.

## Example: one number for five targets

The targets are $y = (1, 2, 2, 3, 12)$ and the model predicts one constant $c$ for all five. Which $c$ minimizes the mean squared error, which minimizes the mean absolute error, and what is each loss at its own minimizer? A classifier gives probability 0.9 to the true class of one example and 0.3 to the true class of another. What are the log loss and the squared error of each, where the squared error of a predicted probability is $(1 - p)^2$ against the target 1, and what happens to both as the probability goes to 0? If the 12 is a typo, which loss should the regressor train on, and which if it is a real value you need to predict?

One constant for five numbers is the simplest regression there is, and the answer still changes with the loss. The explanation derives each loss from its noise assumption and reads the example off the result.

## Explanation

### Squared error, and the mean

Suppose each target is the model's prediction plus bell-curve noise, $y_i = \hat{y}_i + \varepsilon_i$ with $\varepsilon_i \sim \mathcal{N}(0, \sigma^2)$. The bell curve gives a target at $y_i$ the probability density $\frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\big(-(y_i - \hat{y}_i)^2 / 2\sigma^2\big)$: the farther the target is from the prediction, the less likely it is. For $N$ independent examples the probabilities multiply, and the log of the product is

$$
\log \mathcal{L} = \sum_{i=1}^{N} \Big[-\tfrac12 \log(2\pi\sigma^2) - \frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\Big].
$$

The first term does not depend on the predictions, and $1/2\sigma^2$ is a positive constant. So making the data most probable is the same as making $\sum_i (y_i - \hat{y}_i)^2$ smallest. That is the **sum of squared errors**, or divided by $N$, the **mean squared error**. It is what the normal equations for the linear-regression half of [Linear & Logistic Regression](1.27-ML8-linear-logistic-regression.md) minimize, and it carries an assumption about the world: Gaussian noise of one size.

Under squared error the best constant is the mean. Set the derivative of $g(c) = \frac{1}{N}\sum_i (y_i - c)^2$ to zero:

$$
\begin{aligned}
g'(c) &= -\frac{2}{N}\sum_i (y_i - c) = 0 \\
\Longrightarrow\quad c^\star &= \frac{1}{N}\sum_i y_i = \bar{y},
\end{aligned}
$$

and the second derivative $g''(c) = 2$ is positive, so this is the minimum. For the example $\bar{y} = 4$, and the mean squared error there is 16.4.

### Absolute error, and the median

Now assume noise with heavier tails, the Laplace distribution, whose density falls off as $e^{-|y - \hat{y}| / b}$. The same steps give the **mean absolute error**, $\frac{1}{N}\sum_i |y_i - \hat{y}_i|$.

Its best constant is a **median**. Move $c$ a little to the right. It gets closer to every point above it and farther from every point below it, so the error changes at the rate $\frac{1}{N}\big(\#\{y_i < c\} - \#\{y_i > c\}\big)$. The error keeps falling while more points lie above $c$ than below, and stops at a **median**, where the counts on the two sides are as equal as the data allow. With an even number of points every value between the two middle ones ties for the minimum. For the example that is $c = 2$, with mean absolute error 2.4. Each loss at both constants:

| constant | mean squared error | mean absolute error |
|---|---|---|
| mean, $c = 4$ | 16.4 | 3.2 |
| median, $c = 2$ | 20.4 | 2.4 |

The 12 pulls the mean two units away from where the other four points sit and the median not at all. Squared error weights a residual by its square, so one far point dominates the fit. If the 12 is a typo, train on absolute error, which gives every unit of error the same weight, so the outlier pulls no harder than any other point. If the 12 is real and must be predicted, squared error is the loss that takes it seriously.

<ProblemCard id="lf-bake-to-a-quantile" />

The **Huber loss** is squared inside a threshold $\delta$ and linear outside it. It behaves like squared error on ordinary residuals and like absolute error on outliers, with no kink at zero.

### Cross-entropy, and a probability

For a label, bell-curve noise makes no sense. A classifier outputs one probability per class, $\mathbf{p} = (p_1, \dots, p_K)$, usually from a softmax. Write the true class as a **one-hot** vector $\mathbf{y}$, with a 1 in the position of the true class and 0 elsewhere. The probability the model gave to what happened is $p_c$, for the true class $c$, and the loss of one example is minus its log:

$$
\mathcal{L}_{\text{CE}} = -\sum_{k=1}^{K} y_k \log p_k = -\log p_c,
$$

the **cross-entropy**. With two classes it is the **binary cross-entropy** $-[\,y \log p + (1 - y)\log(1 - p)\,]$ of logistic regression. Its gradient with respect to the **logits**, the scores that go into the softmax, is $\mathbf{p} - \mathbf{y}$, predicted minus true. The $1/p_k$ from the log cancels the $p_k$ in the softmax derivative.

Cross-entropy is also the entropy of $\mathbf{y}$ plus the KL divergence $D_{\mathrm{KL}}(\mathbf{y} \Vert \mathbf{p})$ of [information theory](3.1-PS4-information-theory-core.md). A one-hot target has entropy 0, so minimizing cross-entropy is minimizing that divergence.

<ProblemCard id="lf-soft-label-entropy" />

The example at $p = 0.9$ costs $-\log 0.9 = 0.105$ and the one at $p = 0.3$ costs $-\log 0.3 = 1.204$. Their squared errors are 0.01 and 0.49. As $p \to 0$ the squared error tends to 1 and stops, while the log loss grows without bound. A confident mistake is the worst thing a classifier can do, and cross-entropy is the loss that says so.

A weighted cross-entropy multiplies each example's term by a weight for its class. That is how `class_weight` handles imbalance in [Classification Metrics](2.3-ML6-model-evaluation.md).

### Why not squared error for a classifier

Squared error on the probabilities is a loss too, and it trains badly for a reason in the gradient. Through the softmax its gradient carries a factor of order $p(1 - p)$, which vanishes as $p$ approaches 0 or 1, so the push disappears whenever the model is confident. That is harmless when the model is right and fatal when it is wrong. Cross-entropy's gradient is $\mathbf{p} - \mathbf{y}$, with $p_c - 1$ on the true class: a full unit when the model gives the true class no probability, and never damped by a vanishing factor. The implementation measures the two on a confidently wrong example: 1.41 against 0.0001. The second reason is the shape. Cross-entropy on a softmax is convex in the logits, a bowl with one minimum in the probabilities, and squared error on a softmax is not.

### The hinge

The **hinge loss** $\max(0, 1 - y\hat{y})$, with labels $y \in \{-1, +1\}$ and $\hat{y} = \mathbf{w}^\top\mathbf{x} + b$, is the loss behind the [support vector machine](1.15-ML3-kernel-methods-svms.md). It is zero once a point is on the correct side by a margin of 1 and grows linearly inside the margin. It does not try to produce a probability, only to keep correct points a safe distance from the boundary.

<ProblemCard id="lf-hinge-which-points-pull" />

| What you assume, or what you want | Loss |
|---|---|
| Gaussian noise, and the mean | squared error |
| Outliers, and the median | absolute error, or Huber |
| A classifier that outputs probabilities | cross-entropy |
| A classifier with a margin | hinge |

### Scoring a regressor

Training minimizes a loss. A grader reports a **metric**, and three cover regression. With residuals $r_i = y_i - \hat{y}_i$,

$$
\begin{aligned}
\text{MAE} &= \frac{1}{N}\sum_i |r_i|, \\[4pt]
\text{RMSE} &= \sqrt{\frac{1}{N}\sum_i r_i^2}, \\[4pt]
R^2 &= 1 - \frac{\sum_i r_i^2}{\sum_i (y_i - \bar{y})^2}.
\end{aligned}
$$

RMSE is the square root of the mean squared error, so it is in the units of $y$ and ranks models exactly as MSE does, with large errors weighted heavily. MAE is in the units of $y$ and weights every unit of error the same. $R^2$ has no units. It compares the squared error with that of the best constant for the data being scored, their mean. A score of 1 is perfect, 0 is no better than that constant, and anything worse is negative with no lower bound. On test data the constant is the test mean, which the model never saw, so a drift in the target between training and test can push $R^2$ below zero by itself.

<ProblemCard id="lf-r2-of-a-shifted-model" />

Two consequences for a contest. A model trained on absolute error predicts medians and one trained on squared error predicts means. They differ whenever the errors are skewed, so train on the loss that matches the graded metric. Second, an RMSE pooled over several targets is dominated by the target with the largest scale. A parameter near 100 missed by 5% contributes a squared error of 25. A parameter near 1 missed by 10% contributes 0.01 and barely moves the score.

## Implementation

### The example in NumPy

```python
import numpy as np

y = np.array([1., 2., 2., 3., 12.])
for name, c in (("mean", y.mean()), ("median", np.median(y))):
    print(f"{name} {c}: squared loss {np.mean((y - c) ** 2):.2f}  absolute loss {np.mean(np.abs(y - c)):.2f}")
for p in (0.9, 0.3):
    print(f"p = {p}: log loss {-np.log(p):.3f}  squared error {(1 - p) ** 2:.2f}")
```

```output
mean 4.0: squared loss 16.40  absolute loss 3.20
median 2.0: squared loss 20.40  absolute loss 2.40
p = 0.9: log loss 0.105  squared error 0.01
p = 0.3: log loss 1.204  squared error 0.49
```

### Cross-entropy against squared error, at the gradient

Three classes, the true class in the middle, and two sets of logits. The first is mildly wrong. The second is confidently wrong, with all the probability on class 0:

```python
def softmax(z):
    e = np.exp(z - z.max())
    return e / e.sum()

onehot = np.array([0., 1., 0.])
for z in (np.array([2.0, 0.5, -1.0]), np.array([8.0, -2.0, -2.0])):
    p = softmax(z)
    J = np.diag(p) - np.outer(p, p)                        # the softmax Jacobian
    grad_ce = p - onehot
    grad_mse = J @ ((2 / 3) * (p - onehot))                 # chain rule through the softmax
    print(f"p = {np.round(p, 3)}  |grad CE| {np.linalg.norm(grad_ce):.3f}  |grad MSE| {np.linalg.norm(grad_mse):.1e}")
```

```output
p = [0.786 0.175 0.039]  |grad CE| 1.140  |grad MSE| 2.2e-01
p = [1. 0. 0.]  |grad CE| 1.414  |grad MSE| 1.1e-04
```

On the confident mistake the cross-entropy gradient is 1.41 and the squared-error gradient is 0.0001, more than ten thousand times smaller, and the model trained on squared error would barely move.

### From logits, without overflow

$\log p_c$ computed as the log of a softmax overflows once a logit passes about 700, because $e^{z}$ does. The identity $\log p_c = z_c - \operatorname{logsumexp}(\mathbf{z})$ with $\operatorname{logsumexp}(\mathbf{z}) = m + \log \sum_k e^{z_k - m}$ and $m = \max_k z_k$ keeps every exponent at or below 0 and changes nothing mathematically. Libraries work this way, so PyTorch's `CrossEntropyLoss` takes logits and never probabilities:

```python
z = np.array([1000.0, 0.0, 0.0])                          # one huge logit, true class 1
with np.errstate(over="ignore", invalid="ignore", divide="ignore"):
    naive = -np.log(np.exp(z) / np.exp(z).sum())[1]       # exp overflows to inf, so p_1 = 1 / inf = 0 and its log is -inf
m = z.max()
stable = -(z[1] - (m + np.log(np.exp(z - m).sum())))      # z_c - logsumexp(z)
print(f"naive {naive}, stable {stable:.6f}")
```

```output
naive inf, stable 1000.000000
```

The loss is exactly 1000, the gap between the true class's logit and the largest one, and the naive version returns infinity.

### Three scores for one regressor

Two models with the same MAE, then the constant predictor that scores below zero:

```python
from sklearn.metrics import r2_score

def mae(y, p):
    return np.mean(np.abs(y - p))

def rmse(y, p):
    return np.sqrt(np.mean((y - p) ** 2))

def r2(y, p):
    return 1 - np.sum((y - p) ** 2) / np.sum((y - y.mean()) ** 2)

y = np.array([2.0, 4.0, 6.0, 8.0])
for name, p in [("A", np.array([3.0, 3.0, 7.0, 7.0])), ("B", np.array([2.0, 4.0, 6.0, 12.0]))]:
    print(f"model {name}: MAE {mae(y, p):.2f}   RMSE {rmse(y, p):.2f}   R^2 {r2(y, p):.2f}")

# A constant fitted on training data, scored on a test set whose mean has drifted.
rng = np.random.default_rng(0)
y_train = rng.normal(10.0, 2.0, size=500)
y_test = rng.normal(10.8, 2.0, size=500)
const = np.full_like(y_test, y_train.mean())
print(f"\ntraining mean as the prediction, R^2 on test : {r2(y_test, const):.4f}")
print(f"-(mean gap)^2 / test variance                 : {-(y_train.mean() - y_test.mean()) ** 2 / y_test.var():.4f}")
print(f"scikit-learn's r2_score agrees                : {np.isclose(r2_score(y_test, const), r2(y_test, const))}")
```

```output
model A: MAE 1.00   RMSE 1.00   R^2 0.80
model B: MAE 1.00   RMSE 2.00   R^2 0.20

training mean as the prediction, R^2 on test : -0.1454
-(mean gap)^2 / test variance                 : -0.1454
scikit-learn's r2_score agrees                : True
```

Models A and B have the same MAE and differ on everything else. A spreads its error evenly and B puts all of it on one point, and squaring punishes the concentration: RMSE doubles and $R^2$ falls from 0.8 to 0.2. RMSE is never below MAE, and the two are equal only when every error has the same size, as in A. The constant fitted on the training data scores exactly $-(\bar{y}_{\text{train}} - \bar{y}_{\text{test}})^2 / \operatorname{Var}(y_{\text{test}})$ on the test data, below zero without a single bad prediction.
