## The problem

To a computer, an image is a grid of numbers: a 224 × 224 color photo is 224 × 224 × 3 = 150,528 of them. A model has to say what is in the image even though the same thing can appear anywhere, at any size and in any light.

For example, a cat in the top-left corner and the same cat in the bottom-right give completely different numbers in completely different places. In the small pair of grids below, an object of 4 bright pixels is moved from one corner to the other, and the two versions do not share a single bright pixel.

A model that compares images number by number would treat these as unrelated. It has to learn what the object looks like, apart from where it is.

## History

| Year | Model | What changed |
|---|---|---|
| 1998 | LeNet-5 (LeCun et al.) | A small convolutional network reads handwritten digits on bank checks |
| 2012 | AlexNet (Krizhevsky et al.) | A deep network trained on GPUs wins the ImageNet challenge with 15.3% top-5 error, against 26.2% for the next entry |
| 2014 | VGG (Simonyan and Zisserman) | Deeper networks built only from small 3 × 3 filters |
| 2015 | ResNet (He et al.) | Shortcut connections make 152 layers trainable |
| 2015 | U-Net (Ronneberger et al.) | Labels every pixel, first for medical images |
| 2015 to 2016 | Faster R-CNN, YOLO | Find and label many objects in one image |
| 2020 | Vision Transformer (Dosovitskiy et al.) | Splits an image into patches and uses a Transformer |

Much of this progress was measured on the ImageNet challenge (ILSVRC), run on a 1,000-class subset of ImageNet with about 1.2 million training images. AlexNet's win in 2012 is usually taken as the start of deep learning's success in vision.

## The intuition

### Local patterns

Nearby pixels belong together, so a model can start by looking at small patches. A 3 × 3 patch is enough to spot an edge: a bright column next to dark ones is a vertical edge.

### The same filter everywhere

A pattern means the same thing wherever it appears, so the same small set of weights, a **filter**, can slide across the whole image. One 3 × 3 filter has 9 weights, whatever the size of the image, and finds a cat's ear in any corner.

### From edges to objects

Stacking layers builds bigger patterns out of smaller ones: edges, then shapes, then parts, then objects. Each layer sees a wider area than the last: two stacked 3 × 3 layers already see a 5 × 5 patch of the image.
