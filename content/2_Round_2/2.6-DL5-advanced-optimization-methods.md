## Overview

On a quadratic, we can track each eigendirection exactly. Adding stochastic gradients then shows which conclusions survive noise, and removing convexity forces us to state weaker guarantees.

We will develop these cases in order and use them to interpret momentum, schedules, and sharpness-based methods. The assumptions are part of each result. A theorem for a strongly convex quadratic is a useful reference for a neural network, but not a complete description of its training dynamics.

## Convergence rates

**Convex, $L$-smooth, $\eta = 1/L$:**

$$
f(x_T) - f^\ast \le \frac{L\lVert x_0-x^\ast\rVert^2}{2T} = O(1/T).
$$

To reach accuracy $\varepsilon$ takes $O(1/\varepsilon)$ iterations, which is **sublinear**.

**Strongly convex, $\eta = 1/L$:**

$$
f(x_T)-f^\ast \le \Big(1-\frac1\kappa\Big)^{T}\big(f(x_0)-f^\ast\big).
$$

*Sketch for a quadratic.* With $f = \frac12x^\top Ax$ and $x^\ast=0$, the iteration is $x_{t+1} = (I-\eta A)x_t$, so along the eigenvector with eigenvalue $\lambda_i$ the error is multiplied by $(1-\eta\lambda_i)$ each step. With $\eta = 1/L$ the slowest direction is $\lambda_{\min}=\mu$, contracting by $1-\mu/L = 1-1/\kappa$ per step. $\blacksquare$

This is **linear** (geometric) convergence: $O(\kappa\log(1/\varepsilon))$ iterations. The condition number multiplies the iteration count directly.

**Why conditioning hurts, concretely.** With $\kappa = 1000$, each step shrinks the error along the flattest direction by a factor of $0.999$. Reaching $10^{-6}$ needs $\log(10^{-6})/\log(0.999) \approx 13{,}800$ iterations. With $\kappa=10$ the same accuracy takes 131. Meanwhile the *steep* directions are already converged after a handful of steps. This is the ravine picture of [Optimizers & Training Tricks](/module/?id=optimization-adam-sgd), quantified.

## Acceleration

With the momentum-style iteration

$$
y_t = x_t + \beta(x_t - x_{t-1}), \qquad x_{t+1} = y_t - \eta\nabla f(y_t), \qquad \beta = \frac{\sqrt\kappa-1}{\sqrt\kappa+1},
$$

the rate improves to

$$
f(x_T)-f^\ast \le \Big(1 - \frac{1}{\sqrt\kappa}\Big)^T\cdot\text{const},
$$

so $O(\sqrt\kappa\log(1/\varepsilon))$ iterations. At $\kappa = 10^4$ that is a 100× reduction.

**And this is optimal.** Nesterov's lower bound says **no** first-order method (any algorithm whose iterates lie in the span of the gradients seen so far) can do better than $O(\sqrt\kappa\log(1/\varepsilon))$ on this function class. Acceleration is not a heuristic. It saturates the theory.

| Setting | Rate | Iterations for $\varepsilon$ |
| --- | --- | --- |
| Convex, GD | $O(1/T)$ | $O(1/\varepsilon)$ |
| Convex, accelerated | $O(1/T^2)$ | $O(1/\sqrt\varepsilon)$ |
| Strongly convex, GD | $O((1-1/\kappa)^T)$ | $O(\kappa\log\frac1\varepsilon)$ |
| Strongly convex, accelerated | $O((1-1/\sqrt\kappa)^T)$ | $O(\sqrt\kappa\log\frac1\varepsilon)$ |
| Strongly convex, Newton | quadratic | $O(\log\log\frac1\varepsilon)$ |

Accelerated methods are **not monotone**: the loss can rise for a few steps while momentum carries the iterate past the minimum. A non-monotone loss curve is therefore not evidence of a bug when momentum is on.

## Newton's method

Minimize the **second-order** Taylor model exactly rather than the first-order one:

$$
f(x+d) \approx f(x) + \nabla f^\top d + \tfrac12 d^\top\nabla^2f\,d
\;\Longrightarrow\;
d = -\big(\nabla^2f(x)\big)^{-1}\nabla f(x).
$$

**Quadratic convergence.** Near a minimum with positive-definite Hessian, $\lVert x_{t+1}-x^\ast\rVert \le C\lVert x_t - x^\ast\rVert^2$, so the number of correct digits **doubles** each iteration. Reaching machine precision takes 5–6 steps from a decent start.

**Affine invariance.** Under $x = Ty$, Newton's iterates map exactly to the transformed iterates: the method is unaffected by any linear reparameterization, so **conditioning does not appear in its rate.** Gradient descent has no such property, which is why feature scaling matters so much for it and not at all for Newton.

**Why it is not used for deep learning.** The Hessian is $P\times P$: storing it for $P=10^7$ needs $10^{14}$ floats, and inverting it costs $O(P^3)$. Worse, in a non-convex landscape the Hessian is often indefinite, and Newton's step then moves *toward* a saddle rather than away, because the step $-H^{-1}g$ flips sign along negative-curvature directions.

**Practical descendants:**
- **Gauss–Newton / Levenberg–Marquardt:** approximate $H \approx J^\top J$ for least squares and is always PSD.
- **BFGS / L-BFGS:** build a low-rank inverse-Hessian estimate from gradient differences. L-BFGS stores only the last $m\approx10$ pairs, $O(mP)$ memory. Excellent for deterministic full-batch problems, poor with minibatch noise.
- **K-FAC, Shampoo:** block-diagonal or Kronecker-factored approximations, used in large-scale training.
- **Adam** is a diagonal approximation to a preconditioner: $\sqrt{\hat v}$ is a crude per-coordinate curvature estimate, which is why it behaves like a cheap second-order method.

# Logistic regression, where the Hessian changes with w: Newton converges quadratically.
n, d = 500, 4
X = np.column_stack([np.ones(n), rng.normal(size=(n, d - 1))])
w_true = np.array([0.5, 1.0, -2.0, 0.7])
y = (rng.uniform(size=n) < 1 / (1 + np.exp(-X @ w_true))).astype(float)
w = np.zeros(d)
print("Newton on the logistic loss, gradient norm per iteration:")
for k in range(6):
    p = 1 / (1 + np.exp(-X @ w))
    grad = X.T @ (p - y) / n
    H = (X * (p * (1 - p))[:, None]).T @ X / n      # X^T diag(p(1-p)) X / n
    print(f"  iteration {k}: {np.linalg.norm(grad):.1e}")
    w = w - np.linalg.solve(H, grad)

## From Scratch

```python
import numpy as np

def make_quadratic(d=50, kappa=100.0, seed=0):
    """f(x) = 0.5 x^T A x with eigenvalues spread log-uniformly over [1, kappa],
    so L = kappa, mu = 1, and the condition number is exactly kappa."""
    rng = np.random.default_rng(seed)
    Q, _ = np.linalg.qr(rng.standard_normal((d, d)))
    lam = np.logspace(0, np.log10(kappa), d)
    A = Q @ np.diag(lam) @ Q.T
    f = lambda x: 0.5 * x @ A @ x
    grad = lambda x: A @ x
    return f, grad, A, lam.min(), lam.max()

def gd(grad, x0, L, T=1000):
    """eta = 1/L is the exact maximizer of the descent lemma's guaranteed drop."""
    x, path = x0.copy(), [x0.copy()]
    for _ in range(T):
        x -= (1.0 / L) * grad(x)
        path.append(x.copy())
    return np.array(path)

def heavy_ball(grad, x0, L, mu, T=1000):
    beta = ((np.sqrt(L) - np.sqrt(mu)) / (np.sqrt(L) + np.sqrt(mu))) ** 2
    eta = 4.0 / (np.sqrt(L) + np.sqrt(mu)) ** 2
    x, xp, path = x0.copy(), x0.copy(), [x0.copy()]
    for _ in range(T):
        x, xp = x - eta * grad(x) + beta * (x - xp), x
        path.append(x.copy())
    return np.array(path)

def nesterov(grad, x0, L, mu, T=1000):
    """Rate (1 - 1/sqrt(kappa))^T -- optimal for first-order methods."""
    kappa = L / mu
    beta = (np.sqrt(kappa) - 1) / (np.sqrt(kappa) + 1)
    x, xp, path = x0.copy(), x0.copy(), [x0.copy()]
    for _ in range(T):
        y = x + beta * (x - xp)
        xp, x = x, y - (1.0 / L) * grad(y)
        path.append(x.copy())
    return np.array(path)

def newton(grad, hess, x0, T=20):
    """Quadratic convergence: correct digits DOUBLE each step. No kappa in the
    rate, because the method is affine invariant."""
    x, path = x0.copy(), [x0.copy()]
    for _ in range(T):
        x -= np.linalg.solve(hess(x), grad(x))
        path.append(x.copy())
    return np.array(path)

def lbfgs_direction(g, S, Y, gamma):
    """Apply an implicit inverse-Hessian estimate to g using only the last m
    (s, y) pairs -- O(mP) memory instead of O(P^2)."""
    q = g.copy()
    alphas = []
    for s, y in zip(reversed(S), reversed(Y)):
        rho = 1.0 / (y @ s)
        a = rho * (s @ q)
        q -= a * y
        alphas.append((rho, a, s, y))
    r = gamma * q                                   # initial scaling H0 = gamma I
    for rho, a, s, y in reversed(alphas):
        b = rho * (y @ r)
        r += (a - b) * s
    return r

def empirical_rate(losses):
    """Fit log(loss) ~ a + b*t; b < 0 with constant slope means linear
    convergence, a curving line means sublinear."""
    t = np.arange(len(losses))
    ok = losses > 0
    return np.polyfit(t[ok], np.log(losses[ok]), 1)[0]

def top_hessian_eig(grad, x, iters=50, eps=1e-5, seed=0):
    """Power iteration on the Hessian using finite-difference Hessian-vector
    products -- never forms H, so it works for large models. Returns L locally."""
    rng = np.random.default_rng(seed)
    v = rng.standard_normal(x.shape)
    v /= np.linalg.norm(v)
    n = 0.0
    for _ in range(iters):
        Hv = (grad(x + eps * v) - grad(x - eps * v)) / (2 * eps)
        n = np.linalg.norm(Hv)
        if n < 1e-300:
            break
        v = Hv / n
    return n, v
```

`top_hessian_eig` is the practical bridge between this theory and a real model: it estimates $L$ without ever forming the Hessian, and $2/L$ is then a principled upper bound on the learning rate.

L-BFGS is the right tool for small deterministic problems (logistic regression, calibration, physics fits) and the wrong tool for minibatch deep learning: its curvature estimate is built from gradient *differences*, which are dominated by sampling noise when the gradients themselves are stochastic.

## Worked Example

Minimize $f(x) = \frac12(x_1^2 + 25x_2^2)$, the canonical ill-conditioned quadratic.

**Setup.** $\nabla f = (x_1, 25x_2)$, $H = \operatorname{diag}(1,25)$, so $\mu=1$, $L=25$, $\kappa = 25$. Start at $x_0 = (1,1)$, $f(x_0) = 13$.

**Step size.** $\eta^\ast = 1/L = 0.04$, and the stability limit is $2/L = 0.08$.

**Gradient descent with $\eta = 0.04$.** The iteration decouples:

$$
x_1^{(t)} = (1-0.04)^t = 0.96^t, \qquad x_2^{(t)} = (1-0.04\cdot25)^t = 0^t .
$$

$x_2$ is solved **in one step** (the step size is exactly $1/\lambda_2$), and $x_1$ contracts by $0.96$ per step.

| $t$ | $x_1$ | $x_2$ | $f$ |
| --- | --- | --- | --- |
| 0 | 1 | 1 | 13 |
| 1 | 0.96 | 0 | 0.4608 |
| 5 | 0.8154 | 0 | 0.3324 |
| 50 | 0.1299 | 0 | 0.008435 |
| 100 | 0.01687 | 0 | 0.0001423 |

Iterations to reach $f < 10^{-6}$: solve $0.96^{2t}/2 < 10^{-6}$, giving $t > \frac{\ln(2\times10^{-6})}{2\ln 0.96} = 160.7$, so **161 iterations**, verified numerically as 161.

**Nesterov with $\beta = \frac{\sqrt{25}-1}{\sqrt{25}+1} = \frac46 = 0.6667$, $\eta = 0.04$.**

Predicted rate $1 - 1/\sqrt\kappa = 1 - 1/5 = 0.8$ per step versus GD's $0.96$. Running it, $f$ falls below $10^{-6}$ in **40 iterations** against GD's 161, a 4.0× speedup, in line with the $\sqrt{25} = 5$ the theory predicts up to constants. Note that this particular run is monotone: the steep direction is killed in one step and the slow direction contracts at the double root 0.8, so nothing overshoots here.

**Newton.** $H^{-1}\nabla f = \operatorname{diag}(1,1/25)\cdot(x_1,25x_2) = (x_1,x_2) = x$, so

$$
x_1 = x_0 - x_0 = 0 .
$$

**One step, exactly.** Newton solves any quadratic in one iteration regardless of $\kappa$, because the Hessian model is not an approximation here. It is the function.

**Summary.**

| Method | Iterations to $f<10^{-6}$ |
| --- | --- |
| GD, $\eta=0.09$ | never (diverges) |
| GD, $\eta=0.04$ | 161 |
| Nesterov | 40 |
| Newton | 1 |

## Stochastic and Non-Convex Optimization

### Stochastic gradient descent

$$
\theta_{t+1} = \theta_t - \eta g_t, \qquad \mathbb{E}[g_t] = \nabla f(\theta_t), \qquad \operatorname{Var}(g_t) = \frac{\sigma^2}{B}.
$$

The gradient is unbiased and noisy. Unbiasedness is what makes the method work at all, and the variance is what makes its behavior differ from the deterministic theory.

### The noise floor

For a strongly convex $f$ with constant $\eta$, the standard analysis gives

$$
\mathbb{E}\big[f(\theta_T)\big] - f^\ast \ \le\ \underbrace{(1-\eta\mu)^T\big(f(\theta_0)-f^\ast\big)}_{\text{bias: decays}} \;+\; \underbrace{\frac{\eta L\sigma^2}{2\mu B}}_{\text{variance: constant}} .
$$

The first term vanishes, and the second does not. **SGD with a constant step size does not converge to the optimum. It converges to a ball around the optimum** whose radius is proportional to $\eta\sigma^2/B$. That is precisely why loss curves plateau at a noise floor and why decaying the learning rate produces the characteristic step-shaped drops: halving $\eta$ halves the floor.

The formula also tells you the two ways to lower the floor, and their relative cost. Halving $\eta$ halves the floor but doubles the time constant of the bias term. Doubling $B$ halves the floor at twice the compute per step. Which is cheaper depends on where you are: early in training the bias term dominates and a large $\eta$ is worth its noise, while late in training only the floor matters.

### Robbins–Monro conditions

For SGD to converge to the exact optimum, the step sizes must satisfy

$$
\sum_t \eta_t = \infty \quad\text{(enough total movement to reach the optimum)}
$$
$$
\sum_t \eta_t^2 < \infty \quad\text{(accumulated noise is finite)}
$$

$\eta_t = \eta_0/t$ satisfies both. $\eta_t = \eta_0/\sqrt t$ satisfies the first but not the second, and so does constant $\eta$: its steps sum to infinity, but so do their squares. In practice $1/t$ decays too fast, and cosine and step schedules work better empirically, at the price of not converging exactly, which for a non-convex problem is not a meaningful loss anyway.

**Rates.** SGD converges at $O(1/\sqrt T)$ for convex and $O(1/T)$ for strongly convex problems with decaying steps. That is slower than full-batch GD *per iteration*, but each iteration costs $B/n$ as much, so it wins overwhelmingly on wall-clock time.

**Variance reduction.** For a finite sum of $n$ terms, methods such as SVRG and SAGA keep a stale full-gradient estimate and correct it with the current sample, achieving $O((n+\kappa)\log\frac1\varepsilon)$, the linear convergence of full-batch GD at nearly the per-step cost of SGD. They work beautifully on convex finite sums and have never been competitive for deep learning, where the model changes too fast for a stale reference gradient to help.

### Saddle points dominate

At a critical point of a random function in $\mathbb{R}^d$, each Hessian eigenvalue is positive or negative roughly independently. A local minimum requires **all $d$** to be positive, which has probability $\sim2^{-d}$ under a naive model. For $d = 10^6$ that is negligible: almost every critical point is a saddle.

More precisely, random matrix theory (the semicircle law) shows that critical points at high loss have many negative eigenvalues, and the fraction of negative eigenvalues decreases as the loss decreases. The consequence, supported empirically: **local minima in deep networks are mostly of similar quality**, and the real obstacle is not getting trapped in a bad minimum but escaping saddle plateaus, where the gradient is tiny in every direction.

SGD escapes saddles because noise gives it a component along the negative-curvature direction, whereas deterministic GD can stall arbitrarily long on one. Momentum helps too, by carrying velocity through the flat region.

Empirically, minima in wide low-curvature basins generalize better than those in narrow ones. The heuristic: a flat minimum means small perturbations of the parameters barely change the loss, so a small mismatch between the train and test loss surfaces still lands you somewhere good. Large-batch training tends to find sharper minima (one explanation for the generalization gap at large batch size), and SGD noise acts as an implicit bias toward flat regions.

**The caveat is real.** Sharpness is not reparameterization-invariant: rescaling one layer's weights up and the next layer's down leaves the function unchanged while changing every Hessian eigenvalue. So "flat" is not a property of the learned function, and the argument is suggestive rather than rigorous. Scale-invariant sharpness measures exist and are an active area.

### Sharpness-aware minimization

SAM makes the flatness argument explicit by minimizing the worst loss in a neighborhood:

$$
\min_\theta \max_{\lVert\varepsilon\rVert\le\rho} \mathcal{L}(\theta+\varepsilon)
\quad\approx\quad
\min_\theta \mathcal{L}\Big(\theta + \rho\frac{\nabla\mathcal{L}(\theta)}{\lVert\nabla\mathcal{L}(\theta)\rVert}\Big),
$$

using a single ascent step to approximate the inner maximum. Costs two forward-backward passes per step and reliably improves generalization, particularly on vision models trained from scratch.

### The shape of the solution set

**Mode connectivity.** Independently-trained solutions of the same network are typically connected by paths of near-constant low loss, so the minima are not isolated basins but a connected low-loss manifold. This partly explains why ensembling works so well and why weight averaging does.

**Weight averaging (SWA, EMA).** Averaging the weights along the tail of a training run, or maintaining an exponential moving average of them, lands nearer the center of a wide basin than any single iterate does. It costs almost nothing, needs no extra forward passes at inference, and is standard practice in modern training recipes.

**The lottery-ticket observation.** Within a trained overparameterized network, a small subnetwork exists that could have been trained alone to comparable accuracy, if you had known which one and had kept its initialization. This says something about the role of overparameterization in *finding* solutions rather than in representing them.

### Implicit regularization

The optimizer does not merely find *a* minimum of the training loss. With more parameters than data there are infinitely many, and which one you get is determined by the algorithm. Gradient descent on separable logistic regression converges in direction to the maximum-margin solution. On a linear network it prefers low-rank solutions, and SGD's noise prefers flat regions. None of this appears in the loss function, and much of the generalization behavior of deep learning has to be explained by it rather than by explicit penalties.

### From Scratch

```python
import numpy as np

def sgd_noise_floor(grad, x0, L, mu, sigma, eta, T=5000, seed=0):
    """Demonstrates the bias/variance split: the bias term decays geometrically,
    the variance term settles at eta*L*sigma^2/(2*mu) and stays there."""
    rng = np.random.default_rng(seed)
    x, losses = x0.copy(), []
    for _ in range(T):
        noisy = grad(x) + sigma * rng.standard_normal(x.shape)
        x -= eta * noisy
        losses.append(0.5 * x @ x)
    return np.array(losses)

def robbins_monro(t, eta0=0.1):
    """sum eta = inf (reaches the optimum) and sum eta^2 < inf (noise is
    summable) -- both required for exact convergence."""
    return eta0 / (t + 1)

def sam_step(grad, x, rho=0.05):
    """Two gradients per step: one to find the local worst case, one to escape
    it. Approximates min_x max_{||e||<=rho} f(x+e) with a single ascent step."""
    g = grad(x)
    n = np.linalg.norm(g)
    if n < 1e-12:
        return g
    return grad(x + rho * g / n)                    # gradient AT the perturbed point

def swa_update(avg, x, n_averaged):
    """Running mean of the weights along the tail of a run."""
    return avg + (x - avg) / (n_averaged + 1)

def ema_update(shadow, x, decay=0.999):
    return decay * shadow + (1 - decay) * x

def escape_saddle_demo(T=2000, eta=0.01, sigma=0.0, seed=0):
    """f(x, y) = 0.5 x^2 - 0.5 y^2 has a saddle at the origin. Started exactly
    on the stable manifold (y = 0), noiseless GD never leaves; any noise does."""
    rng = np.random.default_rng(seed)
    z = np.array([1.0, 0.0])
    path = [z.copy()]
    for _ in range(T):
        g = np.array([z[0], -z[1]]) + sigma * rng.standard_normal(2)
        z = z - eta * g
        path.append(z.copy())
    return np.array(path)

def sharpness(loss_fn, x, rho=0.05, samples=64, seed=0):
    """Empirical sharpness: the worst loss increase found in a rho-ball. Note this
    is NOT reparameterization invariant -- rescaling layers changes it."""
    rng = np.random.default_rng(seed)
    base = loss_fn(x)
    worst = 0.0
    for _ in range(samples):
        d = rng.standard_normal(x.shape)
        d = rho * d / np.linalg.norm(d)
        worst = max(worst, loss_fn(x + d) - base)
    return worst
```

`escape_saddle_demo` with `sigma=0` and `sigma=1e-3` is the cleanest single experiment in this module: the noiseless run sits on the saddle forever, and an imperceptible amount of noise starts the escape within a few hundred steps.

### Using the Library

```python
import torch
from torch.optim.swa_utils import AveragedModel, SWALR, update_bn

opt = torch.optim.SGD(model.parameters(), lr=0.05, momentum=0.9)

# Stochastic weight averaging: average the tail of the run.
swa_model = AveragedModel(model)
swa_sched = SWALR(opt, swa_lr=0.01)

for epoch in range(epochs):
    train_one_epoch(model, opt)
    if epoch >= swa_start:
        swa_model.update_parameters(model)
        swa_sched.step()

update_bn(train_loader, swa_model)     # BN statistics must be recomputed
```

```python
# SAM in ~10 lines: ascend to the local worst case, then take the real step.
def sam_train_step(model, criterion, opt, xb, yb, rho=0.05):
    loss = criterion(model(xb), yb)
    loss.backward()
    with torch.no_grad():
        norm = torch.norm(torch.stack([p.grad.norm() for p in model.parameters()]))
        eps = []
        for p in model.parameters():
            e = rho * p.grad / (norm + 1e-12)
            p.add_(e)                       # climb to the worst nearby point
            eps.append(e)
    opt.zero_grad(set_to_none=True)
    criterion(model(xb), yb).backward()     # gradient AT the perturbed weights
    with torch.no_grad():
        for p, e in zip(model.parameters(), eps):
            p.sub_(e)                       # step back before updating
    opt.step()
    opt.zero_grad(set_to_none=True)
    return loss
```

`update_bn` is the trap in SWA: averaged weights come with no valid batch-norm running statistics, so a forward pass over the training data is required before the averaged model means anything.

### Worked Example

Take the one-dimensional quadratic $f(x) = \frac12\mu x^2$ with $\mu = L = 1$, so $\kappa = 1$ and the deterministic theory says one step of size $\eta=1$ solves it exactly. Now add gradient noise: $g_t = x_t + \xi_t$ with $\xi_t \sim \mathcal{N}(0, \sigma^2)$, $\sigma = 1$.

**Step 1: the recursion.** $x_{t+1} = x_t - \eta(x_t + \xi_t) = (1-\eta)x_t - \eta\xi_t$.

**Step 2: the stationary variance.** Taking variances of both sides, with $\xi_t$ independent of $x_t$:

$$
v_{t+1} = (1-\eta)^2v_t + \eta^2\sigma^2 .
$$

At the fixed point $v^\ast = (1-\eta)^2v^\ast + \eta^2\sigma^2$, so

$$
v^\ast = \frac{\eta^2\sigma^2}{1-(1-\eta)^2} = \frac{\eta^2\sigma^2}{\eta(2-\eta)} = \frac{\eta\sigma^2}{2-\eta}.
$$

**Step 3: read the numbers.** With $\sigma^2 = 1$:

| $\eta$ | $v^\ast$ | $\mathbb{E}[f] = v^\ast/2$ |
| --- | --- | --- |
| 0.5 | 0.333 | 0.167 |
| 0.1 | 0.0526 | 0.0263 |
| 0.01 | 0.00503 | 0.00251 |
| 0.001 | 0.0005 | 0.00025 |

The floor is very nearly proportional to $\eta$ for small $\eta$, matching the general bound $\eta L\sigma^2/(2\mu B)$. It never reaches zero at any fixed $\eta$.

**Step 4: the step-shaped drop.** Train at $\eta = 0.1$ until the loss plateaus at $0.0263$, then drop to $\eta = 0.01$. The bias term is already zero, so the loss falls to the new floor $0.00251$ within a few time constants, a factor-of-ten drop that looks like sudden learning and is nothing of the kind. Every step decay in a real loss curve is partly this effect.

**Step 5: batch size buys the same thing.** Quadrupling $B$ divides $\sigma^2$ by 4 and hence the floor by 4, at four times the compute per step. Halving $\eta$ divides the floor by 2 at no extra compute per step but doubles the number of steps needed to move a given distance. Neither dominates. The practical recipe of "large $\eta$ early, decay late" is exactly the statement that the bias term matters early and the variance term matters late.

**Step 6: now a saddle.** Take $f(x,y) = \frac12x^2 - \frac12y^2$, whose only critical point is a saddle at the origin. Start at $(1, 0)$, exactly on the stable manifold. Deterministic gradient descent gives $y_{t+1} = (1+\eta)y_t = 0$ forever, so the run converges to the saddle and the gradient shrinks toward zero without escaping.

Add noise of size $10^{-3}$. Each step kicks $y$ by $\eta\sigma = 10^{-5}$, and each kick is amplified by the factor $(1+\eta) = 1.01$ thereafter, so $|y|$ reaches $10^{-3}$ after a few hundred steps. From $|y| = 10^{-3}$, reaching $|y| = 1$ takes $\log(1000)/\log(1.01) \approx 694$ steps. The escape is exponential once started, and the only thing needed to start it is noise far below any level you would notice.

**Step 7: what this says about training.** A deep network's loss surface is full of these. The noiseless analysis above predicts stalling. The observed behavior is a plateau of a few hundred steps followed by a resumption of progress, which is exactly the exponential escape above. This is the concrete sense in which SGD's noise is not a defect to be engineered away.

## Intuition

With stochastic gradients, the update also includes an error term. Its variance and dependence on the parameters determine whether iterates settle, fluctuate, or diverge. With non-convexity, a small gradient need not identify a minimum. These are distinct changes to the analysis, so an explanation based only on “noise helps escape saddles” leaves out much of the actual problem.

Sharpness and averaging methods propose ways to choose or combine solutions. Their effects on generalization depend on parameterization, data, and training. Use controlled comparisons to assess them instead of treating the appearance of a flat two-dimensional loss plot as a proof.
